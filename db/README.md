# 示例库脚本

动态层（`autumn-data-meta-jdbc`）的演示/联调库，三张表覆盖「客户 — 订单 — 明细」的常见形态：

| 表 | 说明 |
| --- | --- |
| `demo_customer` | 客户，`customer_no` 唯一 |
| `demo_order` | 订单，`order_no` 唯一，带 `deleted_flag` 逻辑删除列 |
| `demo_order_item` | 订单明细，按 `order_id` 关联 |

## 两个方言各一份

| 文件 | 目标 |
| --- | --- |
| `schema.sql` | MySQL 8（也可直接跑在 H2 的 `MODE=MySQL`） |
| `schema-postgresql.sql` | PostgreSQL 12+（也可直接跑在 H2 的 `MODE=PostgreSQL`） |
| `seed.sql` | 一次性示例数据，两个方言通用 |

两份 schema 表/列/约束一一对应，**唯一差异是自增主键**：

- MySQL：`id BIGINT NOT NULL AUTO_INCREMENT`；
- PostgreSQL：`id BIGINT GENERATED BY DEFAULT AS IDENTITY`。

这两个写法目前没有共同语法，所以不能合成一个文件。脚本都带 `IF NOT EXISTS`，重复执行不会碰已有数据；普通索引没有放进建表脚本（MySQL 8 不支持 `CREATE INDEX IF NOT EXISTS`），需要时按文件末尾的注释手工建。

## 本机 H2（TCP）初始化

H2 服务端：`D:\opt\h2\start-h2-server.bat`（端口 9092，数据目录 `D:\opt\h2\data`，
启动参数带 `-ifNotExists`，所以第一次连不存在的库会自动建）。

```bat
REM 1. 启动服务端（保持窗口开着）
D:\opt\h2\start-h2-server.bat

REM 2. 初始化 MySQL 兼容库
java -cp "D:\opt\h2\bin\h2-2.5.252.jar" org.h2.tools.RunScript ^
  -url "jdbc:h2:tcp://localhost:9092/autumn_data;MODE=MySQL;DATABASE_TO_LOWER=TRUE" ^
  -user sa -password "" -script "db\schema.sql" -showResults

REM 3. 初始化 PostgreSQL 兼容库
java -cp "D:\opt\h2\bin\h2-2.5.252.jar" org.h2.tools.RunScript ^
  -url "jdbc:h2:tcp://localhost:9092/autumn_data_pg;MODE=PostgreSQL;DATABASE_TO_LOWER=TRUE" ^
  -user sa -password "" -script "db\schema-postgresql.sql" -showResults

REM 4. 示例数据（两个库各跑一次，只跑一次）
java -cp "D:\opt\h2\bin\h2-2.5.252.jar" org.h2.tools.RunScript ^
  -url "jdbc:h2:tcp://localhost:9092/autumn_data;MODE=MySQL;DATABASE_TO_LOWER=TRUE" ^
  -user sa -password "" -script "db\seed.sql"
```

对应的 JDBC URL：

```properties
# MySQL / H2 MySQL 模式
jdbc:h2:tcp://localhost:9092/autumn_data;MODE=MySQL;DATABASE_TO_LOWER=TRUE
# PostgreSQL / H2 PostgreSQL 模式
jdbc:h2:tcp://localhost:9092/autumn_data_pg;MODE=PostgreSQL;DATABASE_TO_LOWER=TRUE
```

真实 MySQL / PostgreSQL：

```bash
mysql -h 127.0.0.1 -u root -p autumn_data < db/schema.sql
psql -h 127.0.0.1 -U postgres -d autumn_data -f db/schema-postgresql.sql
```

方言由 `DialectResolver` 按 `DatabaseMetaData.getDatabaseProductName()` 自动识别
（`mysql` → `MySqlDialect`，`postgre` → `PostgreSqlDialect`，`h2` → `H2Dialect`），
也可以在配置里显式写 `autumn.data.jdbc.dialect` 覆盖。
