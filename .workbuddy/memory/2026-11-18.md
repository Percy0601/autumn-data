## 最终形态
- **只维护一套 MyBatis 风格语句库** `MetaSqlFileStore`：路径
  `{meta-directory}/sql/{数据源}/{命名空间}/{表名}.xml`，classpath 兜底 `meta/{...}`。
- 新增 `MetaSqlGenerator`：七条默认语句 `findList/findPage/findOne/findById/save/update/delete`
  生成在 `AUTUMN-DATA GENERATED START/END` 块，标记头带结构指纹（生成器版本 + MetaTable 指纹）；
  表结构变化**只重写生成块**，标记外自定义语句逐字保留；无标记的手写文件一个字不改、只在内存补齐默认语句。
- 缓存：磁盘 mtime+size 自动重读、结构指纹判活、有界 LRU（files/defaults/declared 三层）、
  代码注册语句为内存覆盖层（优先级高于文件，refresh 不撤销）。
- 删除旧双轨类 `MetaQuery` / `MetaSqlBuilder` / `MetaStatementStore`；`SqlTemplate` 新增内置谓词
  `changed('col')`（读 `CHANGED_KEY` 变更集）；`MetaMapperClient` 补 `validateWritable/validateKey` 写前校验。

## API 口径（用户把控，别改形态）
- `MetaMapper.of(池, 命名空间)` 绑定调用边界；`forNamespace(...)` 是共享缓存的轻量视图。
- 查询 = 参数实体 `MetaClass` + XML 里的 `<if>`；复杂条件写 XML 自定义语句或手写 SQL，不在 Java 侧现拼。
- 写入 = 实体变更集（`changed('col')`），区分「显式置 NULL」与「这一列没动」。
- 删除语义由 XML 的 `delete` 语句决定：有逻辑删除列默认逻辑删除，否则物理删除；可覆盖。
