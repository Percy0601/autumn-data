# 2026-10-31

## autumn-data 项目初始化（脚手架阶段）

参考 `autumn-gateway` 结构，建立 Maven 多模块工程（最外层 `pom` 聚合，兼容 Maven 4.x；父 POM = spring-boot-starter-parent 4.1.1，Java 25）。

### 已落地
- 根 `pom.xml` + 经典 `.gitignore`（对齐 gateway）+ `.gitattributes` + Maven Wrapper（3.9.12）+ README。
- 模块 `autumn-data-jdbc`：依赖 spring-boot-starter-jdbc(HikariCP) / spring-data-commons / jakarta.persistence-api / h2(test)；内置多数据库 `Dialect`（MySQL/PostgreSQL/H2/Default）+ `DialectResolver`（按 DataSource 元数据识别）。
- 模块 `autumn-data-meta`：依赖 spring-boot-starter-jdbc(HikariCP) / freemarker / h2(test)；`MetaConfiguration`（FreeMarker 配置，含 refresh 动态加载）+ `MetaSqlSession` 骨架接口；同样内置 `Dialect`。

### 关键决策
- 两个模块各自维护独立的 `dialect` 包（用户明确只要两个模块，未建 core 模块，重复暂可接受，后续可抽 core）。
- 方言只处理语法差异（标识符引用、分页、自增主键），不持有连接。

### 待办（后续分步）
1. jdbc：实现编译期注解处理器（Spring Data 注解风格 + JPA 注解 → 零反射实现类，参考 Micronaut Data）。
2. meta：实现 FreeMarker 动态 Mapper 执行引擎（.ftl 替代 MyBatis XML，运行时动态加载）。

### 验证
- `mvn clean compile`（在线）通过，两个模块均产出 classes。
