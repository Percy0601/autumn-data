# 2026-11-16

## using 模块新增 MetaDataController：autumn-meta-jdbc 的 HTTP 验证入口
- 新文件：`autumn-data-jdbc-spring-boot-starter-using/src/main/java/xyz/wewin/autumn/data/using/demo/controller/MetaDataController.java`
  与 `src/test/java/xyz/wewin/autumn/data/using/MetaDataControllerTest.java`；
  修改 `src/main/resources/application.properties`，加 `autumn.data.meta.mapper.meta-directory=target/autumn-meta`（产物不污染源码目录）。
- using 模块经 starter 传递依赖 `autumn-data-meta-jdbc`，**不需要新增 pom 依赖**。
- Controller 只操作运行期建出来的演示表 `meta_demo_form`（含 `deleted_flag` 逻辑删除列），
  端点：init / drop / schema / column / rows(POST、GET、GET by id、PUT、void) /
  query/operators / statements / safety / engine / summary。
  DDL 列名过正则、类型过白名单；HTTP 返回的列名统一转小写（H2 元数据是大写）；
  参数与元数据错误统一由 `@ExceptionHandler` 返回 400 JSON。
- 测试用 `@SpringBootTest(webEnvironment = RANDOM_PORT)`：结构断言直接调 Controller 取 `Map`，
  HTTP 冒烟用 JDK `HttpClient`。**踩坑：Spring Boot 4.1.2 的 starter-web 带的是 Jackson 3
  (`tools.jackson.*`)，classpath 里没有 `com.fasterxml.jackson.databind`**，
  测试不要依赖 Jackson 2，也别为此加依赖。
- 验证：`mvn -B -pl autumn-data-jdbc-spring-boot-starter-using -am test`
  → 6 模块 BUILD SUCCESS，using 共 66 个测试全绿（其中新增 3 个）。
